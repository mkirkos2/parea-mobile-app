# Parea

Mobile frontend for the Parea social event discovery application.

## Status

Mobile frontend under development

## Stack

- Expo
- React Native
- TypeScript
- Expo Router

## Installation

```bash
npm install
```

## Development

### Browser Development

```bash
npx expo start --web
```

### Physical Device Development

```bash
npx expo start --dev-client --tunnel
```

## Validation Commands

```bash
# Type checking
npx tsc --noEmit

# Linting
npm run lint

# Expo project validation
npx expo-doctor

# Dependency check
npx expo install --check
```
